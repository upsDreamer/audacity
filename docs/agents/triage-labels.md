# Triage Labels（分诊标签）

各技能以五个规范分诊角色进行沟通。本文件将这些角色映射到本仓库问题跟踪器实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本跟踪器中的标签  | 含义                             |
| -------------------------- | ----------------- | -------------------------------- |
| `needs-triage`             | `needs-triage`    | 维护者需要评估该问题             |
| `needs-info`               | `needs-info`      | 等待报告者提供更多信息           |
| `ready-for-agent`          | `ready-for-agent` | 已完全明确，可交由自主智能体实现 |
| `ready-for-human`          | `ready-for-human` | 需要人工实现                     |
| `wontfix`                  | `wontfix`         | 不予处理                         |

当技能提到某个角色（例如"打上 AFK-ready 分诊标签"）时，使用本表中对应的标签字符串。

如需自定义，编辑"本跟踪器中的标签"列以匹配实际使用的词汇。
